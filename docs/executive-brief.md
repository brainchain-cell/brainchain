# Brainchain Lab — executive brief

**Decision:** Build a small, independent publication that helps professionals finish real work with AI, then check the result.

**Positioning:** “AI workflows for work you have to get right.”

**Primary audience:** Consultants, analysts, project managers and small-team operators who already use an AI assistant but need repeatable methods for briefs, meeting records and recurring work. Builders are a secondary path, not a prerequisite for the site.

**The product:** A task-led learning library. Each lesson connects an input, a sequence of actions, a review step and a usable outcome. Tool coverage supports those tasks. The newsletter brings readers back to a useful lesson. The eventual differentiator is original evidence: sample inputs, outputs, failure cases and a clear checking method.

**What changes now:** Replace the narrow, mostly text-only homepage with a warm editorial system: ivory paper, forest-green ink, large serif headlines, an interactive workflow example, four task paths and three illustrated lesson cards. Introduce Krishna as the accountable founder. Add search and filters to Learn, contents links and local completion to lessons, and a dedicated Subscribe page with an explicitly illustrative issue. Reuse all 11 existing lessons, four paths and 29 directory entries; preserve their route slugs and current publication dates. Keep Next.js and static export.

**90-day done:** By 30 January 2027, the redesigned site has been reviewed and released through the existing production account; three flagship workflows have original input/output/check packs; one welcome sequence has been verified end to end; eight high-priority tool entries have dated plan/source reviews; and five target readers have completed a workflow and provided structured feedback. These are proposed acceptance targets, not claims about current users or results.

**Cut from the next 90 days:** Accounts, a custom LMS, certificates, leaderboards, a paid community, daily AI news as the main product, mass-produced tool comparisons and speculative sponsorship promises. Keep the existing updates and tool URLs available, but take the news feed out of the primary navigation. No new framework, domain or CMS migration.

**Business model:** Free editorial learning first. Retain the existing labelled Make link. MailerLite and n8n remain possible commercial relationships to verify, not approvals to announce. Teach Cursor, OpenAI, Anthropic and Notion on editorial merit.

**Release boundary:** This v1 is a private review build. Moving it onto brainchainlab.com requires the founder’s existing GitHub/Cloudflare production workflow and a real inbox check of the subscription journey. Client work, employer branding and confidential examples stay outside Brainchain Lab.
