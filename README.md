# Brainchain

Practical AI guides and an official-source announcement index. The site is a Next.js static export (`output: "export"`) deployed on Cloudflare Pages. `npm run build` writes the site to `out/`.

## Local operation

- `npm ci`
- `npm run dev`
- `python3 scripts/test_updates.py`
- `python3 scripts/refresh_updates.py`
- `npm run build` produces `out/`.

## Publishing model

Guides live in `_posts/` and require `status: published` to appear. They are editorial guidance with source links, not fabricated hands-on reviews. Official updates contain attributed headlines and outbound links only, not copied article bodies or AI-generated reviews.

The GitHub Actions workflow refreshes announcements daily at approximately 08:47 India time (03:17 UTC). It accepts only approved HTTPS domains, valid recent dates and plain-text titles, deduplicates links, retains the previous collection on source failure and builds before committing. It uses no paid API. GitHub scheduled jobs can be delayed and may be disabled after repository inactivity; monitor the Actions page.

Cloudflare Pages builds the default branch and publishes `out/`. The canonical host is `https://brainchainlab.com`. A Pages Function at `functions/_middleware.ts` 301-redirects `www.brainchainlab.com` and `brainchain.pages.dev` to that host, including the path and query string. Preview hostnames (`*.brainchain.pages.dev`) are not redirected.

## Analytics

Cloudflare Web Analytics is cookieless. The beacon is rendered only when `NEXT_PUBLIC_CF_BEACON_TOKEN` is set at **build** time. Leave it unset and the export contains no analytics script. See `.env.example`.

In the Cloudflare dashboard, open Web Analytics, choose the `brainchainlab.com` site, and open Manage site. Copy the `token` value from the JavaScript snippet (`data-cf-beacon`). Add it as a Pages environment variable named `NEXT_PUBLIC_CF_BEACON_TOKEN` (Production, and Preview if preview traffic should be counted), then redeploy so the static export picks it up.

If the Pages project also has Web Analytics set to automatic injection, switch that site to “Enable with JS Snippet installation” (or disable automatic injection). Otherwise the beacon can be added twice.

## Affiliates

The Make signup URL is `MAKE_AFFILIATE_URL` in `src/lib/constants.ts`. Guides that already cite Make show one labelled link. `/disclosure` describes the commission.

No paid AI integration is configured. New full-length articles are not generated by the RSS workflow.
