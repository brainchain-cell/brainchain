# Brainchain

Practical AI guides and an official-source announcement index. The existing Next.js project is preserved, updated, and exported as static files to keep hosting portable and avoid a paid application server.

## Local operation

- `npm ci`
- `npm run dev`
- `python3 scripts/test_updates.py`
- `python3 scripts/refresh_updates.py`
- `npm run build` produces `out/`.

## Publishing model

Guides live in `_posts/` and require `status: published` to appear. They are editorial guidance with source links, not fabricated hands-on reviews. Official updates contain attributed headlines and outbound links only, not copied article bodies or AI-generated reviews.

The prepared GitHub Actions workflow refreshes announcements daily at approximately 08:47 India time (03:17 UTC). It accepts only approved HTTPS domains, valid recent dates and plain-text titles, deduplicates links, retains the previous collection on source failure and builds before committing. It uses no paid API. GitHub scheduled jobs can be delayed and may be disabled after repository inactivity; monitor the Actions page.

**Activation is not yet complete.** The workflow must be pushed to the original GitHub repository's default branch, Actions must allow repository writes, and a suitable public host must build each updated commit. A private Sites preview is separate from this GitHub workflow and does not automatically receive its updates.

The current Vercel Hobby plan restricts commercial use. Before affiliate launch, connect a suitable host within the approved zero-new-spend budget. Do not purchase hosting or renew a domain without the owner's approval.

## Launch checklist

1. Verify Namecheap domain ownership, renewal and DNS.
2. Connect a free suitable public host to the GitHub repository, using `npm run build` and `out/`.
3. Set the intended primary domain and verify HTTPS and article URLs.
4. Activate and manually run the GitHub workflow; verify a real host deployment follows its commit.
5. Add canonical URLs and a sitemap for the confirmed production origin.
6. Enrol in affiliate programs only with the owner's details and authorization. Replace ordinary links only with verified approved affiliate URLs and update disclosures at the same time.

No affiliate IDs, credentials, paid AI integration or analytics are configured. New full-length articles are not generated by the RSS workflow.
